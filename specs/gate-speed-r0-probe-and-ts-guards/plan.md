### Pre-Cover Six Blind-Spot Axes

1. **Security / privacy / authority / data-loss**:
   - `$TMPDIR` self-test cache dir uses per-UID path, rejects symlinks (`! -L`), requires current-UID ownership (`-O`) and exact mode `0700` (falling back to uncached `--self-test` if unsafe), writes stamps atomically (`mktemp` + `mv -f`), and never caches skipped (`evidence_card_leak_self_test_skipped`) or failed runs.
   - `r0-leakage-audit.md` and `check-ccl-skills.sh` never auto-execute discovered scripts under `~` and never print private `.yaml` names or personal paths.
   - `.github/actions/setup-validation-tools/action.yml` verifies `RIPGREP_SHA256` via `sha256sum --check` on **every** run (both cache hit and cache miss) before `sudo install`.
2. **Concurrency & lifecycle**:
   - Concurrent `check-ccl-skills.sh` workers in `regression-fast`/`regression-heavy` write unique `mktemp` files inside the `0700` cache dir and atomically `mv -f` onto the SHA-256 stamp filename; no partial reads or clobber.
   - `packages/opencode-plugin/ccl-skills.ts` pairs omitted-`callID` invocations per `(sessionID, tool)` FIFO, rolls back both the synthetic queue entry and `pendingSkills` entry if `tool.execute.before` throws (e.g., blocked edit/task), and clears session state on `session.idle`, `session.compacted`, `session.deleted`, and `dispose`.
   - `test-repo-gates` parallelizes only suites audited by `test_lane_isolation.py`.
3. **Resource bounds**:
   - Self-test cache prunes old `.ok` stamps when count exceeds 64.
   - `ccl-skills.ts` caps `pendingSkills` at 64 entries and synthetic `callID` queues at 64 entries per session (evicting oldest) so orphaned `before` calls without `after` cannot grow unboundedly.
4. **Rollout / migration ordering**:
   - `pack.test.mjs` moves to `scripts/check-pack-suite.mjs` in the same commit that updates `package.json` `test:pack`; `opencode-adapter.ts` and `install-opencode.sh` copy only `ccl-skills.ts`, so `packages/opencode-plugin/tsconfig.json` does not enter `~/.config/opencode/plugins/`.
5. **Over-broad absolute**:
   - `CCL_SKILL_EVIDENCE_CARD_STRICT_SELFTEST=1` and `CCL_SKILL_NO_SELFTEST_CACHE=1` bypass the self-test cache so `Makefile` and dedicated detector tests always exercise the full uncached `self_test()`.
6. **Enumeration-completeness**:
   - Checked all 5 `GATE_JOBS` in `.github/workflows/ci.yml` (`repository-gates`, `code-review-regressions-1`, `code-review-regressions-2`, `regression-fast`, `regression-heavy`), all 4 supported hosts in `packages/ccl-skills-npm/package.json` (`Claude Code`, `Codex`, `OpenCode`, `Antigravity`), all `.py` files repo-wide under `python3 -W error` (`client-terminal-ansi-check.py` fixed; immutable `eval/evidence/.../recompute-aggregates.py` documented out-of-scope), and all 3 docs mentioning `check-public-sanitization.py` outside `make test` (`AGENTS.md`, `README.md`, `docs/CONTRIBUTING.md`).

### Security Four Questions

1. **Caller-controllable inputs**: `$TMPDIR` / `CCL_SKILL_SELFTEST_CACHE_DIR` contents and permissions, ambient `CCL_SKILL_BASE_REF`, `ALIAS_AUDIT_CMD`, cached CI `ripgrep` tarball bytes, and OpenCode plugin hook inputs (`sessionID`, omitted/empty `callID`, `args`, `metadata`).
2. **Blast radius if forged or mishandled**: Pre-planted symlink or world-writable cache stamp could skip `--self-test` or overwrite user files; unverified cached CI tarball could install tampered `rg`; mismatched or leaked `callID` state could attribute a stale/unowned `Skill` load or grow memory unboundedly.
3. **Trust roots**: Per-UID `0700` non-symlink cache directory + SHA-256 of `check-evidence-card-leak.sh`; pinned `RIPGREP_SHA256` checked unconditionally before `install`; `completedSkill()` realpath + active-bytes verification in `ccl-skills.ts`.
4. **Negative cases**: Symlinked or `0777` cache dir → cache bypassed, `--self-test` still runs; 1-byte edit or broken detector mutant → cache miss / no `.ok` stamp written; skipped git-fixture `--self-test` → no `.ok` stamp written; `before` throws without `callID` → rolled back so next `callID`-less call still pairs; >64 orphaned `before` calls → bounded at 64.
