# Attention-Budget Debt Reduction, Git-Env Isolation & Review-Diff Suite Acceleration (Batch 2a)

## Context & Roadmap Continuity

Following **Batch 1** (`PR #240`, `a151098e21ab29e7a827a58b834c503012ca2eee`) in [specs/ci-gate-npm-slimming/plan.md](../ci-gate-npm-slimming/plan.md#four-batch-repository-optimization-roadmap), this plan governs **Batch 2a** (`ccoalm/attention-budget-and-suite-speed`), keeping the candidate packet below `code-review`'s `200,000`-byte ceiling while pairing each touched upstream owner (`code-review` and `skill-extraction-workflow`) with an executable `RED-baseline` fix:

1. **`code-review` Git-env isolation & suite speed (`RED-baseline`)**: Scrub 30 `GIT_*` routing/config keys + prefixes via `git_environment()` in `review_diff.py` and `review_diff_clients.py` (5-way parity in `check-repo-hygiene.py`); batch `Candidate.bind()` `rev-parse` + `digest(head, untracked)` (`14 -> 10` `git` spawns); clone one `$work/template-repo` via `cp -RP` + `jq` in `test_review_diff.sh` (`36 -> 2` fixture / `54 -> 18` total `git init`; `47.97s -> 43.48s` `N=5` median).
2. **`code-review` entrypoint slimming (`semantic-control`)**: Bring `skills/code-review/SKILL.md` (`5,917 -> 4,270` words, `-12,649B`; `word_over_limit` `8 -> 7`, `0` `>40L` fences) under `5,000` words by relocating runnable staged/harness/consult recipes + internal parser/envelope detail to `references/manual-invocation-and-prompts.md` (`141L -> 286L`).
3. **`skill-extraction-workflow` size-gate CR parity, speed & paired-eval signal cleanup (`RED-baseline`)**: Compute `base_ref_over_count` in `check-size-budget.sh` from `head_ref_infos` SHA-1 reuse + `load_base_blobs` + `ref_info_for_text` (`0` `git grep` calls), replace 3 `diff`/`ls-files` calls with `git status --porcelain=v1 -z --no-renames -uall` (`8 -> 5` clean `git` calls, `1.08x`), and clean up pre-`init` interrupted sibling session files/project dirs in `skill-paired-eval.py:collect_transcripts`.
4. **`skill-extraction-workflow` reference & entrypoint slimming (`semantic-control`)**: Bring `references/dual-track-review-gate.md` (`573L -> 479L`; `ref_over_limit` `4 -> 3`) under `500L` via `references/dual-track-debug-prompts.md` (`101L`, `##`-structured) and trim `SKILL.md` (`113,670B -> 113,487B`, `15,586 -> 15,554` words).

Out-of-scope follow-ups remain durably tracked in [specs/ci-gate-npm-slimming/plan.md](../ci-gate-npm-slimming/plan.md#four-batch-repository-optimization-roadmap) under the repository maintainer / requester: remaining attention-budget items (`Batch 2b`), multi-thousand-line script modularization and shared Python Git-env helper extraction (`Batch 3`), and hook/gate suite tail optimizations (`Batch 4`). Delivery stops at a Ready PR + green CI pending explicit user merge authorization.
