4. **Rollout / migration ordering**: `hooks/agy-bridge.py` (`PR #235`, `e8ad14a`) already landed before this prose update, so runtime verification of `Partial read` byte chunks is already live.
5. **Over-broad absolute**: Replaces the over-broad unconditional `<200 lines / 8 KB` rule with an observable pre-call/post-call conditional (`ByteOffset` `read_file` with `Showing lines`/`Partial read` headers vs all other outputs), without creating a self-adjudicated "if you think it won't truncate" loophole.
