# Read-Discipline Host Predicate: Contiguous Span Readers vs Middle-Truncating Outputs

Align the always-on read discipline (`agent-context/session-start.md`, `agent-context/session-policy.md`) and its owning extraction rule (`skills/skill-extraction-workflow/SKILL.md`, `skills/skill-extraction-workflow/references/source-to-skill-extraction.md`) with file-read tools that return contiguous line/byte spans (`Showing lines A-B of T` or `Partial read (lines A-B of T). Showing bytes S-E of Z`, such as Antigravity `read_file`).
