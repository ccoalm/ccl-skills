## 一、两笔欠账的独立核实（先于任何设计）

### 欠账 A —— 判据要求了一个工具链产不出的输出形态

039 的冻结判据（`specs/039-design-first-shrink/plan.md` 判定表第 4 行 + 检索协议末段）要求 `休眠` 是**独立通道的正面认定**：复核方看过三项检索的全部命中后，认为都不构成落地后的触发证据。

**实测：没有任何可用的独立通道能产出这个形态。**

| 通道 | 输出形态 | 证据 |
| --- | --- | --- |
| kimi `review` / `challenge` | findings 列表 | `skills/code-review/scripts/kimi_review.sh:62` —— `case "$MODE" in review\|challenge) ;; *) die_inconclusive bad_mode` |
| opencode `review` / `challenge` | findings 列表 | `skills/code-review/scripts/opencode_review.sh:170`，同形 |
| codex `review` / `challenge` | findings 列表 | `skills/code-review/scripts/codex_review.sh:54`，同形 |
| claude `consult` | 有 `answer` 字段 | 只存在于 `claude_review.sh`；**与起草方同家族**，独立性不成立；且被设计为 `gate_eligible:false`、rc=2（`skills/code-review/SKILL.md:257,260`） |

空 findings 的语义是「没有可阻断的异议」，不是「我认定不存在触发证据」——缺席不等于断言。039 已登记这一点（dispositions.md「由此暴露的判据缺陷」节），并注明「修复方向尚不明确」。

**这是同类第二次复现**：判据 v1（`休眠` = 零命中 grep）因规则自身文本永远命中而不可满足；v2（正面认定）因工具链产不出裁定而不可达。两次都是**判据写了一个机器做不到的条件**。按本仓「同类复现以删除收束」的判据（问的是谓词是代理还是不变量，不是补丁计数），本轮不再为满足该谓词去造新通道，而是换掉谓词本身。

### 欠账 B —— 槽位 2/9 的合规三臂覆盖不足

039 登记的说法是：「台账行主张的是 10 条任务上 `3/10 → 10/10`，本探针只界定了其中 1 条」，待补证动作为「扩到 10 条任务 = 150 次调用」。

**该登记本身有误，两处。**

1. **分母误读。** 台账行（`skills/skill-extraction-workflow/references/source-register.md:58`）的 `3/10 before, 10/10 after` 是**同一条用例的 10 轮**，不是 10 条任务：`docs/skill-taxonomy-optimization-plan.md:400` 明写「它的收益由前后各 10 轮（3/10 → 10/10）承担」；同文件 :375 的常驻层 A 臂对照表（`3/10 | 5/10 | 10/10`）同样以轮为单位。该用例即 `route-opencode-global-snapshot-audit`（`eval/routing-tasks.jsonl` 第 79 行），正是探针所用的那一条。故「扩到 10 条任务」不成立，「150 次调用」也不成立。

2. **真正的缺口是位移锚未排除，且更严重。** 突变只删了 description 里的 A 子句，而同一条 description 里还有 B 子句：

   | 记号 | 文本 | 出处 |
   | --- | --- | --- |
   | A | 「核查全局安装点（~/.config/opencode 等）旧快照是否遮蔽本仓技能」 | 槽位 2/9 的被测规则；台账行 :58 主张它使该用例 3/10 → 10/10 |
   | B | 「本仓（ccl-skills 等共享技能仓）OpenCode 项目配置·命令治理」 | **另一轮**（`route-opencode-project-config` 2/10 → 10/10）的产物，不在台账行 3/10 基线所在的表面上 |

   B 带 `OpenCode`、`本仓`、`技能仓` 全部字面 token，单独就可能吸住该题面。删 A 后仍 5/5，因此读不出「A 不承重」——它落在**未被排除的位移解释**里，正是 039 自己在槽位 28 主动排除过的那个形态（该槽位自带位移探针）。

   合规的补证是加**双删臂**（A+B 同删）与**删 B 单臂**（归因），成本 2 臂 × 5 次 = 10 次调用，不是 150。

## 二、批 1：判据 v3 —— 把 `休眠` 换成机械可判谓词

### v3 谓词（本节即冻结物）

一个槽位判 `休眠`，当且仅当其台账行经**冻结脚本**判定命中下列之一，且复跑一致：

| 记号 | 条件 | 判定者 |
| --- | --- | --- |
| D1 · 不可达目标 | 该行**全部** firing-path 定位符命中 unrunnable-target：目标是 `.rb`/`.sh`/`.py` 可执行制品，而全仓（`specs/` 之外的 `*.sh\|py\|rb\|yml\|yaml` 与 `Makefile`）无任何入口提及其基名 | `register-firing-path-resolution.rb`（039 已落地该 advisory） |
| D2 · 自指目标 | 该行**全部** firing-path 定位符的目标文件即该规则文本所在文件——不存在规则文本之外的决策点去取用它 | 本轮新增的确定性判定，同一脚本 |

**「全部」是硬条件**：任一定位符既非 D1 也非 D2，该行不得判 `休眠`，退回有序判据重走。

**独立通道的角色回到它能产出的形态**：对**谓词与其输入**提 findings——脚本是否漏判、advisory 是否误标、某槽位的定位符解析是否正确。不再要求它下裁定。039 判据的其余部分（`superseded` / `收窄` / `keep` 三条、`keep` 的 (a)(b) 两项、随机性系统的统计控制四条、零损失义务表）**逐字不动**。

### 为什么这不是「作者放宽判据以拿到自己想要的删除」

这正是 039 裁定所防的那件事，故本轮把防线写成机械形态，而不是承诺：

1. **谓词对全台账生效，不对样本生效。** 落地后必须对全部台账行跑一遍，并如实报出它标出的**每一行**——包括不在 039 样本里的、起草方并不想删的。一个只放行那 6 条候选的谓词会当场暴露。
2. **谓词只产出终态，不产出删除。** 判 `休眠` 之后，该行绑定的动作仍须逐条填零损失义务表；删不删是那一步的事。
3. **v2 不是被绕过，是被证明不可达**，且取消 v2 的裁决权不在起草方：修法方向由用户裁定（本轮记录在案），本文件不自判其正当性。
4. **反向可证伪**：若 D1/D2 在全台账上一条都不命中，或命中面明显宽于 039 的六个候选，本批即宣告谓词设计失败并如实报出，不做二次调参。

## 三、批 2：槽位 2/9 的双删臂（预注册，先于任何一次运行）

| 项 | 值（冻结） |
| --- | --- |
| 观察点 | `eval-routing-bank.rb`，用例 `route-opencode-global-snapshot-audit`（`eval/routing-tasks.jsonl:79`） |
| 已有臂（039 实测，直接引用不重跑） | 控制 5/5；删 A 5/5；安慰剂 5/5 |
| 新臂 1 | **删 A+B**（双删），5 次 |

| 判定函数 | 每臂 5 次中路由到 `skill-extraction-workflow` 的次数 `pass_count ∈ 0..5` |
| 效应判据 | `pass_count(控制) − pass_count(某臂) >= 3` 方可认定该臂删掉的文本承重 |
| 假阳上限 | 沿用：安慰剂 − 控制 `>= 3` 即判探针失效（039 实测差为 0，探针有效） |
| 模型 | `eval-routing-bank.rb` 默认（本机 claude-haiku-4-5），与 039 同 |

**读数规则（先于运行冻结）**

- 删A+B 掉下来、删B 未掉 → **A 承重**（B 是位移锚，掩盖了 A 的效应）→ 槽位 2/9 走 `keep` (b)。
- 删A+B 掉下来、删B 也掉下来 → **B 承重、A 不承重**（或 A/B 冗余互备）→ 槽位 2/9 按 `superseded` 路径走零损失义务表（义务由 B 承接）。
- 删A+B 仍 5/5 → **A、B 均不承重于该用例**，台账行 :58 的因果主张在当前表面下失效 → 槽位 2/9 按 `收窄`/`superseded` 重判，并**另行登记台账行 :58 的主张与当前表面不符**（该登记本身是本轮产出，不是删除授权）。

**边界如实标注**：本探针只界定该一条用例在当前 grader 与当前 description 表面下的行为。它不外推到其它用例，也不追认或推翻台账行当初在旧表面上的测量。
