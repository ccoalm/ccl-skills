## 按预注册读数规则定终态

`C = 5`，`X = pass_count(删A+B) = 0`，`Y = pass_count(删B) = 5`。

- `C − X = 5 >= 3` → 被删文本承重，效应判据成立。
- `C − Y = 0 < 3` → 落入预注册表第一行，其字面结论为「A 承重；B 是掩盖了 A 效应的位移锚」。

**这个字面结论经独立通道推翻，见下。终态不取 `keep`。**

## 终态：非终态 —— **对称冗余，冻结判据里没有这个形态**

矩阵是：控制 5/5、删 A 5/5、删 B 5/5、删 A+B 0/5。它说的是 **A 与 B 各自充分、各自都不必要，二者联合必要**。

- 走不通 `keep`：判据 keep(b) 要求因果制品能读出「若无这条规则，那个决定不会是这样」。删 A 单臂 5/5 恰恰显示**没有 A，那个决定一模一样**。keep 不成立。
- 也不取 `superseded`：它要求零损失义务表可填满，而 B 只被证明在**这一条用例**上承接了 A 的义务，A 主张的义务面不止这一条。且这个方向指向起草方想要的结果（收缩轮多一次删除），更不该由起草方在结果出来后自取。

**这是本轮登记的第三个同类缺陷：冻结判据要求了一个形态，而实测落在它没有的格子里。** 前两个是「零命中 grep 不可满足」与「正面认定不可产出」；这一个是「对称冗余无对应终态」。三次都属同一类——判据的终态集合对真实证据形态不完备。

预注册读数表第一行的措辞是本轮的一处实质缺陷：它把 `C−Y < 3` 直接读成「A 承重」，而该条件同样被对称冗余满足。**不追改已冻结的映射**，如实登记它错在哪。

**槽位 2 / 9 终态：`证据不足`（非终态），但性质与 039 完全不同**——039 是「探针不合格」，本轮是「探针合格、结果有效，而判据无格子可落」。裁定交用户。

**D1 要证的是「不存在任何机械入口到达该文件」——一个对开放集合的全称否定。** 调用形态的集合不封闭（枚举器 API 可以再多、路径可以运行时拼、还可以经 `eval`/间接层），所以任何静态扫描都只能证「在我枚举的这些形态下没有」，永远证不到「不存在」。加宽枚举面能挡住已知的三种，挡不住第四种，而判据要的是全称。

**这是本轮登记的第四个同类判据缺陷，也是最重的一个**：

| # | 缺陷 | 形态 |
| --- | --- | --- |
| 1 | `休眠` = 零命中 grep | 不可满足（规则自身文本永远命中） |
| 2 | `休眠` = 独立通道正面认定 | 不可产出（通道只输出 findings） |
| 3 | 对称冗余无对应终态 | 判据的终态集合不完备 |
| 4 | `休眠` = 无任何机械入口到达 | **不可判定**（对开放集合的全称否定） |

四个都是同一个根：**`休眠` 这个终态要求证明一个否定，而本仓能产出的证据形式全都只能证肯定。** 前三个还能靠换判据修，第四个不能——它不是措辞问题。

**处置：不加宽扫描，把结论降回去。** 槽位 18–21 维持 `证据不足`。`d1_widened_scan.sh` 保留在树里，但它的地位从「终态认定器」降为**已枚举形态下的否定证据**——一个真实但不充分的输入。它的注释与本节同步说明这一点。

第 12 条（复原窗口竞态）已修：复原前先校验目标仍逐字节等于脚本自己写下的突变内容，不等就中止并保留现场，绝不覆盖。
