## Pre-Cover Six Axes & Mechanism-Operability Check

### Pre-Cover Six Axes

1. **Security / privacy / authority / data-loss**:
   - Negative case 1: `hooks/guard-broad-local-test.sh` shares the `-test.sh` suffix substring; matching `*-test.sh` would strip a live PreToolUse hook from `dist/assets`. Guarded by restricting the `hooks/` exclusion to `^hooks/test_[^/]+$` and pinning `guard-broad-local-test.sh` presence in `basic.test.mjs`.
   - Negative case 2: In `ccl-skills.ts:sameSkillDirectory`, ignoring arbitrary extra files in `skills/<name>/scripts/` would let a tampered non-test script (`scripts/extra.sh`), symlink, or hardlink pass `OpenCode` owner verification. Guarded by ignoring **only** single-link regular non-symlink files (`st.isFile() && !st.isSymbolicLink() && st.nlink === 1`) matching `^(?:test_.+|.+\.test\.sh)$` directly inside `<skill>/scripts/`, while `scripts/extra.sh`, `scripts/test_symlink.sh`, `scripts/test_hardlink.sh`, and `scripts/owner-probe.sh` edits continue to reject.
2. **Concurrency & lifecycle**:
   - Negative case: Parallel mutant workers in `test_init_policy_matrix.sh` (`INIT_POLICY_MATRIX_JOBS=4`) run `init_policy_matrix.py` concurrently. Each process allocates its own `TemporaryDirectory()` and restores `sys.argv`/`stdout`/`stderr` in a `finally:` block, sharing zero mutable filesystem paths.
3. **Resource bounds**:
   - Negative case: `init_policy_matrix.py` previously created `270` temp directories and spawned `270` Python interpreters per invocation; the in-process runner bounds each invocation to `1` temp directory and `4` CLI-parity subprocesses (`<= 6` total Python spawns).
4. **Rollout / migration ordering**:
   - Negative case: Existing `OpenCode` installations upgrading from an older snapshot that contained `skills/*/scripts/test_*` files run `writeShared()` in `opencode-adapter.ts`, which removes entries present in `old.entries` and absent from `next` (`L269-274`) and prunes empty owned directories (`L289-294`) cleanly once `preflight` confirms the old snapshot was unmodified.
5. **Over-broad absolute**:
   - Negative case: Excluding `**/tests/**` or `**/test_*` across all `skills/**` subtrees would remove `skills/tighten-doc/scripts/tests/svg/figure-contract.json` (used by `figure-lint.py`), `skills/tighten-doc/scripts/tests/doc/control.md` (pinned in `contract-anchors.tsv`), and `skills/test-artifact-management/references/test_gen_report.py` (invoked by `run_pytestless.py`). The predicate scopes strictly to `hooks/test_[^/]+`, `scripts/owner-dispatch/test.sh`, and `skills/[^/]+/scripts/(?:test_[^/]+|[^/]+\.test\.sh)`.
6. **Enumeration-completeness (set-diff)**:
   - Set-diffed all `1,069` tracked files under `roots` in `build-assets.mjs`: exactly `107` files match the repo-test predicate (`18` under `hooks/test_*`, `1` at `scripts/owner-dispatch/test.sh`, `73` under `skills/*/scripts/{test_*,*.test.sh}`), and a cross-repo reference scan confirmed `0` runtime hooks, adapters, `SKILL.md` files, `references/*.md` files, or `contract-anchors.tsv` rows invoke or pin any of those `107` paths as shipped runtime assets (`validate-skill.sh` only mentions `test_generic_r0_leak_scan.sh` and `test_validate_skill_credential_cwd.sh` in `--glob '!...'` exclusions).

### Mechanism-Operability Check

- **Author dogfood**: Base-relative gates (`check-ccl-skills.sh`, `check-size-budget.sh`, `impact-chain-gate.rb`, `check_review_evidence_present.py`, `shared_git_surface_gate.py`) run against `origin/main` (`push` + `pull_request` target in `.github/workflows/ci.yml`); stateless gates (`init_policy_matrix.py`, `register-firing-path-resolution.rb`, `check-contract-anchors.sh`, `validate-skill.sh`) run identically across worktrees and synthetic fixtures.
- **Marginal cost**: Cuts routine local `check-ccl-skills.sh` / strict `--self-test` / `test_init_policy_matrix.sh` latency by tens of seconds per run with zero manual cache-maintenance burden.
- **Trust-model fit & loosening/premise check**: No gate verdict is loosened — every validator optimization preserves existing verdicts (and fail-closes malformed empty/out-of-root contract-anchor rows and `CHECK_INSTALL_VISIBILITY=1` Ruby extraction errors): fresh per-case namespace `main()` execution from cached compiled bytecode + 4-call CLI smoke, `heading-exists` necessary-condition prefilter on raw markdown before fence stripping, per-file read/AST memoization, and single-pass fixed-string byte counting inside `root`. The npm asset exclusion narrows distributed files to runtime assets only while `sameSkillDirectory` skips single-link regular `scripts/{test_*,*.test.sh}` only when one-sided (still comparing bytes when present on both sides) and preserves all host smoke and `shipped-doc-lint-repo` checks.
