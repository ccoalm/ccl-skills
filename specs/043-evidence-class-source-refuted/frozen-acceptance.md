# 043 冻结判据 —— 先于任何一次闸改动

**本文件在 `impact-chain-gate.rb` 被触碰之前提交，顺序由 git 历史可核。**

## 为什么要先冻

本轮的起因是 042 被 `impact_chain_behavior_evidence_missing` 挡住。如果由"想让 042 过"的一方来定这一轮的成败，那这就是一次**为放行特定改动而做的闸变更**——042 轮已经实测过：作者对自己改动的判断系统性偏向让它落地（marker 偏向新文本、阈值在不利结果后被调、隔离闸被用出同义反复）。

所以：**判据在动闸之前冻结，且用合成用例表述，不用 042 的 diff。042 能不能过是事后的观察结果，不是本轮的目标。**

## 问题

证据分类里没有「一条规则触发正常、但内容为假」这一类。

| 主张类型 | 恰当证据 | 现有分类 |
| --- | --- | --- |
| 行为/路由变更 | `RED-baseline`（施加突变、观察转红） | 有 |
| 义务不变的改写 | `semantic-control` | 有 |
| **一条陈述被一手源否证，须撤回** | **一手源否证 + 零损失义务保全** | **无** |

现状后果：一次事实更正只能硬套 `RED-baseline`（造不出来，因为删掉假陈述往往无可测行为差异）或误标 `semantic-control`（会被 owner 级 RED 底线拦下）。于是**假陈述留在技能里比删掉它更容易**。

## 拟加的类：`source-refuted`

**不是豁免，是换一种证据。** 声明该类的行必须同时满足：

1. `observed-failure: no` —— 这条闸问的是规则有没有失灵；被撤回的陈述**触发正常**，它只是假的。
2. 证据列含**至少一个外部一手源引用**（URL），即否证该陈述的出处。
3. 证据列含一个**零损失义务对照**的可解析指针（文件路径 + 锚），且该目标非空。
4. 该 owner 包在本轮的**规范面净变化 ≤ 0 字节**。撤回一句假陈述会让包缩小；这条挡住"借事实更正之名夹带新规则"。

第 4 条是**机械下限，不是证明**：净删除仍可能在别处夹带，那由 dual-track 的零损失审查兜。本轮不假装机械检查能替代它。

## 冻结的验收用例（合成，全部确定性、不调模型）

| # | 用例 | 无新类时 | 有新类时 | 这条在防什么 |
| --- | --- | --- | --- | --- |
| **A** | 撤回一句陈述的 diff + 合规 `source-refuted` 行（源 URL、零损失指针、净字节 < 0） | **红** | **绿** | 类确实解决了那个问题 |
| **B** | **真的行为变更**（新增一条规范规则）披 `source-refuted` 标签 | 红 | **仍红** | 类不能变成万能豁免 |
| **C** | `source-refuted` 行**缺源 URL** | 红 | **仍红** | 证据要求是实的 |
| **D** | `source-refuted` 行**缺零损失指针**或指针目标为空 | 红 | **仍红** | 义务保全要求是实的 |
| **E** | `source-refuted` 行标了 `observed-failure: yes` | 红 | **仍红** | 分类语义不得自选 |
| **F** | 既有的 `RED-baseline` / `semantic-control` / 两个 `not-required` 类的现有行为 | 绿/红按现状 | **完全不变** | 不得回归 |

**通过条件 = 六条全中。** 任何一条不符即本轮未完成，不得以"主要目标达成"结案。

## 明确不作为判据的东西

- **042 的 diff 能否通过**。它不在测试集里；本轮跑完之后如实观察并记录，但它不是成败依据。
- 净字节数、改了多少行、跑了几轮。

## 停止线

- 若为让用例 A 变绿而需要放宽 B–F 中任何一条，**停止并交裁决**：那说明这个类的形状不对，不是门槛该松。
- 若实现后发现第 4 条（净变化 ≤ 0）会误伤正当的事实更正（例如撤回时必须补一句说明它为何被撤回，导致净增），**停止并交裁决**，不得自行改判据——这正是 042 轮"阈值在不利结果后被调"的形态。
