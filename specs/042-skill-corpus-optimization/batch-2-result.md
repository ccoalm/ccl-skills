# 批 2 结果 —— 结论已撤回：测法无效

> **本文件下方的结论（「零条可删、039 的冗余前提不成立」）已撤回。** 用户质疑实验是否成立，复核后确认**测法有致命缺陷**，其负结果不构成证据。撤回依据见本节；原文保留在下方，作为该测法为何失效的记录。

## 撤回：marker 测的是词汇回声，不是义务

给 L106 的 marker 是 `source-register` / `impact-chain-gate`——**这两个词只有 L106 提到**。删掉该行，模型自然说不出没见过的词。`10/10 → 0/10` 这个"完全分离"近乎**同义反复**：它证明的是「删掉唯一提到某词的行，模型不再说那个词」，不是「closeout 会做得更差」。对照臂救不了——它用的是同一种同义反复（`route-to-shared` 也只在 L107）。

**直接反证**（读 `minus_L106` 臂的实际回答，两次均如此）：

> 覆盖范围：lifecycle owners + **upstream/downstream** + siblings
> 格式：`owner | direction(**upstream/downstream**/sibling) | status | changed-file-or-reason`

**L106 的实质义务（双向映射）在它被删掉之后依然在**，由 L103 的映射格式承接——那一行字面就写着 `direction(upstream/downstream/sibling)`。所以 L106 与 L103 在双向义务上**重叠**，这恰恰是冗余的证据，方向与本文原结论相反。

## 隔离闸主动制造了这个错误

我为「候选 marker 必须组内唯一承载」建的机械闸，**逼我只能选那些只有这一行提到的词**——也就是逼我做同义反复。一个方法缺陷被我做成了闸，然后用它挡掉别的读数。这条比单次误判更该记：**把未经检验的方法假设机械化，等于把它变成不可见的系统性偏差。**

## 其余三条威胁（均指向高估承重）

| 威胁 | 方向 |
| --- | --- |
| 喂的是 22 行切片而非 338 行全文；从 22 行删 1 行的相对扰动远大于真实情况 | 系统性**高估**承重 |
| 只测一个决策点（closeout 产出什么） | 双向，更可能低估 |
| 单模型、单措辞、无随机化 | 未知 |

两条最强威胁都指向本文原本得出的那个结论。**一个系统性偏向某结论的实验，得出那个结论时不算证据。**

## 正确的测法应该是什么

1. **按义务判分，不按词汇**：marker 换成该规则**要求做到的事**（容许改写），最好由独立判分方读回答，不用正则。
2. **候选 marker 不要求唯一承载**（该要求只适用于对照臂），否则必然退化成同义反复。
3. **用全文，不用切片**，或至少同时报切片与全文两种读数。
4. 同一条规则测**多个决策点**，不只一个。

## 这推翻了什么

039 的诊断链是：仓库只能加不能删 → **所以存在冗余可删** → 需要一套退役判据。

第一次真正测「能不能删」，答案是**不能**。文件大不是因为被冗余撑大，是因为**它编码了很多条互不重复、各自在起作用的规则**。

后果有三：

1. **杠杆 2 没有可下手处**，本批到此为止，不硬删。
2. **size 闸的 flat-or-shrink 在这个文件上是不可满足的**：内容既然承重，「只准平或缩」就等于要求删掉正在起作用的东西才能落地一条有证据的更正。批 1 记的那条闸缺陷，现在有实测支撑。
3. **真问题换了个样子**：规则各自有用、但合起来超出注意力预算。这不是「删」能解的，是**杠杆 3（位置/结构）**——把规则挪到它触发的地方，让决策点上只有相关的那些进上下文。

## 方法学副产品

隔离闸的作用域先前被我用错：它只该管**对照臂**（必须唯一承载，否则测不出损失）；**候选臂正相反**——marker 在别处也有承载，正是「这条与那条冗余」的证据本身。拿对照的规矩去卡候选，等于把要测的现象当噪声筛掉。已修正并写进脚本注释。
