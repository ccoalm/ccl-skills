# 全文两臂测量：撤回那句假陈述是否改变行为

## 为什么重做

切片探针（只喂那一条 bullet）报「无差异」，我据此得出「042 拿不出 RED 基线」。但那台仪器我自己已判定有缺陷——**不合格仪器的零结果不是效果不存在的证据**。所以用完整语料重测。

## 设计

| 项 | 做法 |
| --- | --- |
| 两臂 | 完整 `SKILL.md`，从 git ref 取：`9c11837`（含假陈述） vs 042 分支头（已撤回）。仅差那一条 bullet，−304 字节 |
| 判据 | [`full-arms-frozen-rubric.txt`](full-arms-frozen-rubric.txt)，由**只见场景、不见任何技能文本**的独立通道产出，运行前冻结 |
| 判分 | 独立判分方按处置立场判，容许任何措辞，**看不到臂来源** |
| 规模 | 每臂 n=10，三轮独立复现 |

## 读数

| 复现 | old（含假陈述） | new（已撤回） |
| --- | --- | --- |
| 1 | 6/10 | 8/10 |
| 2 | 5/10 | 10/10 |
| **3** | **10/10** | **7/10** |

**判定：NOT_REPLICATED。** 前两轮方向一致（+2、+5），第三轮反向（−3）。

## 结论

同一输入下**旧臂在 5/10、6/10、10/10 之间跳**，新臂在 7/10–10/10 之间跳；两臂分布大幅重叠，**读数被跑间方差主导，不被臂主导**。要在这种方差下分辨十几个百分点的效应，n 需上到几百。

所以准确的说法不是「这句话没有效果」，而是：

> **它的行为效果（若存在）小于这套仪器在合理成本下的分辨力。**
