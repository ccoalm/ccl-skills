# 交付收尾问答（严格依据规则清单）

**A) 放置前的前置动作（全部列出）**
1. **现读目标结构**：目录树/容器层级须本次实时读取，不依赖技能文本、记忆或历史快照里的结构，也不按链接标题猜父容器。
2. **记下预期受众/访问边界与预期 owner**：这两项不是投放时自拟的，须以交付任务/需求/内容密级等**既有记录**为源，且该记录须独立于本次落点选择、也独立于投放者；owner 同理，须是任务/需求/密级记录载明的那一个（目标容器自身的 owner/边界记录不算预期来源）。
3. **先读目标容器当前生效的访问边界与控制方（owner）**，用于和上一步的预期做比对。

**B) 目录选择的判据**
落点选**最具体的稳定容器**：能长期容纳同类内容的最深目录/明确的专题容器才是合法父节点。标题相似本身不构成父子依据——不得只因某篇既有文档标题相近就把新文档挂在它下面；但在“页面即容器”的承接面上，现读结构确认该节点确为承载同类的稳定容器时，它可以作父节点。

**C) 报「已同步」前须核的全部核验项**
1. 列出该交付物**全部**面（远端副本/各附件/各导出件/历史多代产物）——列不出面等于没跑。
2. 逐面标**四态之一**（互斥且完备）：已投放 / 授权不投放 / blocked / 待安全处置。
   - 标「已投放」须带**回读到的标志**（新增段落/版本号/修订时间），只写“已上传/命令成功”不算；发布面有机器校验器的要跑一遍，人读 sweep 照跑（校验绿只是代理不是替代）。
   - 本轮涉及新建/移动/落点变化的面，还须把 ①b 的**定位回读**与**边界/owner 回读**全部跑完，且结果落在“符合预期”，否则不得标已投放。
3. 多代并存的另标：当前版稳定入口、旧版退役方式（仅归档或原位标过期二选一）。
4. 待安全处置的触发按客观命中或有权 owner 决定判断，拿不准按命中处理。
5. 有交互源导出的，另标已全展开再导，并对照交互源清点承载性实体。
6. **有 blocked 面或待安全处置面即不得报已同步。**
7. 含「选点自评、未经独立复核」标注的面，不得出现「已同步」字样，须报「已投放 N 面，其中 M 面选点自评、待复核」并附完整路径+责任复核方的清单，待独立复核确认或纠错重投后才可改报已同步。

**D) 发布后发现可见范围比预期更宽**
内容一放进更宽容器即已实际暴露，事后回读**只能发现、不能撤销**。此时**只能按 `待安全处置` 处理**，转出给收敛权威（安全/内容 owner）结案，结案前不得报已同步；**不得**因该情形的裁决权也归边界权威就把它记回 blocked——已暴露与未放入是两个互斥态，动作和结案条件不同。

**E) 放置前对目标容器访问边界的要求**
先读目标容器当前生效的访问边界与控制方（owner）。若比预期受众宽、owner 落在非预期主体、或读不到/无法核验以致排除不了这些情形，**都不得放入**；确知比预期窄的也不得径直放入（按 blocked 修复后投放）。比预期宽/无法核验/owner 非预期的：换合规容器，或停下转出裁决，该面裁决前按 blocked 记（注意：此 blocked 只适用于**尚未放入**的面）。

**F) 发布后发现落点 owner 非预期主体**
按 `待安全处置` 处理，转出给**持内容归属治理权的一方**（不是目标容器现任控制方）裁决结案；若同一面同时命中其他待安全处置情形（如边界更窄但 owner 非预期），待安全处置吸收，不得以 blocked 绕开转出。

**G) 交付信息里文档路径怎么给**
给**完整路径**（不是只给链接），但披露以该读者对结构的既有可见范围为限——层级名称本身受访问限制、读者无权见的，受限段不写进面向该读者的交付信息；**完整路径仍须保留在核验记录中，并交付给对结构有权的 owner/读者**，不得因省略让任何有权复核方也拿不到全路径。

**H) 预期受众/边界/owner 无既有记录可依**
不自拟基线。只有两条路：
1. 转对应权威裁决（边界那半归边界权威，owner 那半归持内容归属治理权的一方），由裁决记录一并载明该面的访问边界与预期 owner，裁决前该面按 blocked 记；或
2. 只放入读回其生效边界确认**仅投放者本人可及**的私有/工作容器（且不授权新建任何副本，仅限投放者本就可持有的那份工作副本）。
但第 2 条是**暂存，不是交付**——不构成对外交付，原本要交付的那个面仍按 blocked 记，不得以「已放入私有容器」抵充该面的已投放。

**I) 边界权威裁决怎么才算数**
只有**能从该权威侧回读到**的裁决记录才算数，投放者不得代收、转述或自行记录授权。且权威身份本身须独立锚定：以承接面/组织既有的**权威名册或治理记录**核验，投放者不得自行指认权威人选；名册核不到按「权威身份无法核验」处理，经既有升级通道问明归属，问明前该面保持 blocked。

**J) 定位核验是否构成结构移动或权限变更的授权**
不构成。清单明确：「本节只核不改：结构移动与权限变更各自仍需其自身的授权，定位核验不构成任何一种。」
