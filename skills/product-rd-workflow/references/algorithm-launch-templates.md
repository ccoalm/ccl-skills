# AI/Algorithm Launch Templates

Use this when drafting or reviewing launch materials for a new or iterative AI/algorithm capability.

## Full Materials

| Material | Use |
| --- | --- |
| [Algorithm launch SOP](algorithm-launch-sop.md) | Full gate for new and iterative algorithm capabilities. |
| [Evaluation report template](algorithm-launch-evaluation-report-template.md) | Required report shape for metrics, datasets, comparison, engineering baselines, chain validation, risk, and launch recommendation. |
| [Launch checklist](algorithm-launch-checklist.md) | Review checklist for evidence links, owners, results, and status. |
| [Launch execution spec](algorithm-launch-execution-spec.md) | Detailed rules for baseline freeze, experiment/gray rollout, composite-chain validation, monitoring, rollback, eval-set governance, third-party comparison, and post-launch operation. |
| [Team handbook](../../../docs/algorithm-service-launch-handbook.md) | Human-readable team entry point; not an execution gate. |
| [Skill usage handbook](../../../docs/algorithm-service-launch-with-skills.md) | Human-readable guide for asking OpenCode/Codex/Claude to use CCL skills; not an execution gate. |

Workflow:

1. Read the [Algorithm launch SOP](algorithm-launch-sop.md).
2. Choose new capability or iteration.
3. Fill the [Evaluation report template](algorithm-launch-evaluation-report-template.md).
4. Run the [Launch checklist](algorithm-launch-checklist.md).
5. Use the [Launch execution spec](algorithm-launch-execution-spec.md) for baseline freeze, experiment/gray rollout, composite-chain validation, monitoring, rollback, eval-set governance, third-party comparison, and post-launch operation.

Missing required evidence is no-go unless the launch owner records the exception scope, risk, owner, and follow-up date in the launch material.
