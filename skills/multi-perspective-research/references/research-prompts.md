# 多视角调研提示词模板

四步模板。`[TOPIC]` 为研究主题，`[ROLE]` 为用户角色/立场。既可由 agent 自己按步执行（推荐，可结合真实检索），也可作为独立 prompt 交给任意 LLM——**独立 prompt 模式下没有可回查的工具调用记录，全部发现强制 `ungrounded`，产出一律按探索性草稿交付**。执行时遵守 SKILL.md 的证据落地纪律：模拟视角输出是假设级证据，载重结论须真实核验。

## 1. 多视角枚举

```text
我要研究 [TOPIC]。请用 5 个不同的专家视角分别分析：

1. 实践者——每天与 [TOPIC] 打交道的人。学院派漏掉了什么？哪些现实约束总被忽略？
2. 研究者——多年研究该领域。同行评审证据实际说明什么？证据在哪里与流行认知矛盾？
3. 怀疑者——认为主流观点有误。最强的反方论证是什么？支持者刻意回避了什么证据？
4. 利益追踪者——追踪资金与激励。谁从当前叙事获利？哪些激励在塑造研究/舆论方向？
5. 历史对照者——见过类似规律。存在哪些历史先例？那些先例的走向能告诉我们什么？

每个视角输出三项：
- 核心立场（2 句话）
- 支撑该立场的最强证据
- 只有这个视角会告诉我、其他视角不会说的一件事
```

视角可按主题替换（监管者、终端用户、竞争者、安全研究员等），标准是：替换后的视角必须会给出与其余视角**不同**的答案。

## 2. 矛盾图

```text
基于以上 5 个视角，绘制矛盾图：

1. 哪些视角的主张直接冲突？逐条列出冲突双方的具体主张。
2. 哪个视角证据最强？哪个最弱？为什么？
3. 哪一个问题被回答后，能化解最大的矛盾？
4. 所有视角都同意什么？（连对手都确认的，大概率为真。）
5. 没有任何视角提及什么？（整个领域的盲区，常是最有价值的发现。）
```

## 3. 合成简报

```text
把 5 个视角与矛盾图合成为一份研究简报：

1. 一段话总结：向只有 60 秒、但需要 nuance 而非标题的决策者汇报 [TOPIC]。（轻量模式：不得用"向决策者汇报"框架，改为探索性概览，且开头标注"未分析：跳过矛盾图/自评"）
2. 关键发现（≤5 条；仅四步全跑时按可靠性排序，轻量模式给不排序列表）：每条标注哪些视角支持、哪些视角质疑。
3. 隐藏关联：一个只有合看全部视角才会显现的非显然联系。
4. （仅四步全跑时）可操作建议：基于全部证据，[ROLE] 应该做出什么具体的不同行动？
5. 前沿问题：哪一个问题被回答后，会改变我们对 [TOPIC] 的整体理解？
```

轻量模式（只跑 1+3）使用本模板时**删去第 4 项**，第 2 项改为不排序、且**不带"支持/质疑视角"标注**的发现列表（排序与视角冲突标注都依赖第 2 步矛盾图），并在产出开头带"未分析（跳过矛盾图/自评），探索性草稿"标注：可操作建议、载重结论、可靠性排序、视角冲突标注只允许出现在跑完第 2、4 步并附待核验清单的完整交付里。

## 4. 自评（同行评审）

```text
以严格审稿人的标准评审上面这份简报：

1. 给每条关键发现打置信度（高/中/低），并说明依据的证据强度。
2. 整份简报最弱的环节在哪里？
3. 是否有某个视角被过度代表、拉偏了结论？
4. 是否漏了第 6 个应该纳入的视角？是谁？
5. 哪些结论目前只有推理支撑、没有可核验来源？逐条列出，作为人工核验清单。
```

## 使用提示

- 快速了解：只跑 1 + 3，产出只作探索性概览（附 grounded/ungrounded 标注），不得输出可操作建议、载重结论或可靠性排序。支撑重要决策：四步全跑，且第 4 步列出的"待核验清单"必须在行动前用真实检索/一手来源关闭。
- agent 有检索能力时，第 1 步每个视角先做真实检索再作答，把结论从 `ungrounded` 升级为 `grounded`。
- 方法出处与完整实现参见 `github.com/stanford-oval/storm`（MIT）——作为方法论参考；若要实际运行该第三方系统（它会发起检索与 LLM 调用），走团队常规的第三方代码审查/沙箱授权路径，不要默认直接执行。
